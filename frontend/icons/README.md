# App Icons and Splash Screens

## Icon Requirements

Create app icons in the following sizes and place them in the respective directories:

### Android Icons
- `android/app/src/main/res/mipmap-hdpi/ic_launcher.png` - 72x72
- `android/app/src/main/res/mipmap-mdpi/ic_launcher.png` - 48x48
- `android/app/src/main/res/mipmap-xhdpi/ic_launcher.png` - 96x96
- `android/app/src/main/res/mipmap-xxhdpi/ic_launcher.png` - 144x144
- `android/app/src/main/res/mipmap-xxxhdpi/ic_launcher.png` - 192x192

### Splash Screen
- `android/app/src/main/res/drawable/splash.png` - 1284x2778 (recommended)

## Icon Generation Tools

You can use these online tools to generate icons:
- https://makeappicon.com/
- https://www.appicon.co/
- https://icon.kitchen/

## Temporary Icons

For now, you can use the default Capacitor icons. After the first build, Capacitor will generate default icons that you can replace with your custom ones.

## Custom Branding

For YESAYA MINISTRY branding:
- Use navy blue (#1e3a5f) as primary color
- Use gold (#FFD700) as accent color
- Include cross or church symbol in the icon
- Use clean, modern design
